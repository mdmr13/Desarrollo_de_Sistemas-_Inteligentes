Glosario (todo con base en Machine Learning)

- Pandas: es una biblioteca de Python utilizada para manipular, organizar, analizar y limpiar datos. Permite trabajar fácilmente con tablas de información mediante estructuras llamadas DataFrame
    
- Matplotlib: es una biblioteca de Python utilizada para crear gráficas y visualizaciones de datos 
    
- Scikit-learn (Investigar que datos de prueba maneja): es una biblioteca de Python especializada en Machine Learning, contiene herramientas para preparar datos, entrenar modelos, hacer predicciones y evaluar su rendimiento, incluye algoritmos como: 
    

- Árboles de decisión
    
- Regresión lineal y logística
    
- K-Nearest Neighbors (KNN) 
    
- Máquinas de vectores de soporte (SVM)
    
- Random Forest
    
- Clustering

- Árbol de decisión: es un algoritmo de Machine Learning que toma decisiones mediante una estructura parecida a un árbol, formada por preguntas o condiciones, cada respuesta lleva a una nueva decisión hasta llegar a un resultado final, se usa principalmente para clasificación y también puede utilizarse para regresión 
    
- Matriz de confusión: es una herramienta que permite evaluar el rendimiento de un modelo de clasificación comparando las predicciones de modelo con los resultados reales. En una clasificación binaria normalmente contiene: predicción positiva, predicción negativa, real positivo, verdadero posidtivo, falso negativo, real negativo, falso positivo, verdadero negativo. Sirve para identificar qué tipos de errores está cometiendo el modelo, no solamente cuántos aciertos tiene
    
- Sobreajuste (Overfitting): ocurre cuando un modelo de Machine Learning aprende demasiado bien los datos utilizados para entrenarlo, incluyendo características particulares o ruido de esos datos, pero tiene dificultades para funcionar correctamente cond atos nuevos. 
    

  

Glosario general

- Falso positivo: ocurre cuando el modelo predice que algo pertenece a la clase positiva, pero en realidad pertenece a la calse negativa
    
- Falso negativo: ocurre cuando el modelo predice que algo pertenece a la clase negativa, pero en realidad pertenece a la clase positiva
