Actividad 1
Definición de las 5 actividades estructurales del proceso de software: Comunicación, Planeación, Modelado, Construcción y Despliegue

1) Comunicación: Consiste en interactuar con el cliente o usuario para conocer sus necesidades, requisitos y expectativas sobre el software que se va a desarrollar
2) Planeación: Consiste en organizar el trabajo que se realizará, estableciendo las actividades, tiempos, recursos, costos y responsabilidades necesarias para desarrollar el proyecto
3) Modelado: Consiste en diseñar y representar cómo funcionará el software antes de construirlo. Se elaboran diagramas, modelos y diseños que sirven como guía para el desarrollo
4) Construcción: Consiste en desarrollar el software mediante la programación y realizar pruebas para detectar y corregir errores, asegurando que funcione correctamente
5) Despliegue: Consiste en entregar e implementar el software para que el usuario pueda utilizarlo. También incluye recibir comentarios, realizar ajustes y brindar mantenimiento cuando sea necesario
