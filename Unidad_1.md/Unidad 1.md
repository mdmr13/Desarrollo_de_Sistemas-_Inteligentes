**Act 1.2 Casos de uso de Zabbix 
1) Monitoreo de servidores: Permite vigilar servidores y detectar problemas como el alto uso de CPU, memoria insuficiente, poco espacio en disco o servicios caídos. 
2) Monitoreo de redes: para supervisar routers, switches, puntos de acceso y conexiones de red
3) Monitoreo de bases de datos: para supervisar el funcionamiento y rendimiento de bases de datos, identificando lentitud, conexiones excesivas o falta de recursos
4) Monitoreo de aplicaciones y servicios: para comprobar que aplicaciones y servicios importantes estén funcionando correctamente
5) Monitoreo de infraestructura y dispositivos IoT: para supervisar temperatura, sensores, dispositivos inteligentes, máquinas y otros equipos conectados

1) Un sistema inteligente es un sistema tecnológico capaz de realizar tareas de manera automatizada dentro de un entorno determinado, utilizando técnicas de inteligencia artificial.
